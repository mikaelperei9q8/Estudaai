🎓 EstudaAI — Seu companheiro de estudos

EstudaAI é uma plataforma de estudos inteligente desenvolvida para ajudar estudantes a aprender, pesquisar, organizar conteúdos e melhorar seu desempenho escolar com o auxílio da Inteligência Artificial.

O objetivo é tornar os estudos mais simples, interativos e eficientes, reunindo diversas ferramentas educacionais em um único aplicativo.

✨ Funcionalidades

🤖 Inteligência Artificial

- Assistente de estudos com explicações didáticas.
- Resolução de dúvidas passo a passo.
- Análise de questões enviadas por imagem.
- Respostas adaptadas ao nível escolar do estudante.

🔎 Pesquisa inteligente

- Pesquisa de conteúdos na internet.
- Consulta de fontes e referências.
- Verificação de informações.
- Apresentação de respostas organizadas.

📚 Ferramentas de aprendizagem

- Criação de resumos automáticos.
- Mapas mentais.
- Flashcards para memorização.
- Quizzes com perguntas de múltipla escolha.
- Correção e avaliação de redações.

🧮 Ferramentas matemáticas

- Calculadora científica.
- Funções trigonométricas.
- Conversor de unidades.

⏱️ Organização dos estudos

- Temporizador Pomodoro.
- Biblioteca para salvar respostas e materiais.
- Acompanhamento do progresso.
- Estatísticas de aprendizagem.
- Sistema de conquistas.

🎨 Personalização

- Temas visuais.
- Ajuste do tamanho da fonte.
- Perfil do estudante.
- Preferências de aprendizagem.

🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Integração com Inteligência Artificial.
- Integração com pesquisa na internet.
- Armazenamento de dados do aplicativo.

🚀 Como executar

1. Baixe os arquivos do projeto.
2. Abra o arquivo "estudaai-pesquisa.html" em um navegador compatível ou ambiente de execução adequado.
3. Configure as integrações necessárias de Inteligência Artificial.
4. Acesse as ferramentas e comece a estudar.

Importante: a integração com a IA depende de um serviço externo configurado. Não coloque chaves secretas de API diretamente no código disponibilizado publicamente.

🎯 Objetivo do projeto

O EstudaAI busca democratizar o acesso a ferramentas inteligentes de aprendizagem, oferecendo aos estudantes recursos que auxiliam na compreensão dos conteúdos, na organização da rotina e no desenvolvimento acadêmico.
